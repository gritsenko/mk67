# Руководство разработчика (Development Guide)

В этом документе описаны процессы разработки, доступные команды, правила внесения изменений и чеклист проверки перед коммитом.

---

## 🛠 Системные требования и установка

- **Node.js**: версии 18.x или выше (рекомендуется 20.x LTS).
- **Пакетный менеджер**: npm 9.x или выше.
- **Окружение**: Windows, macOS или Linux.

Установка зависимостей:
```bash
npm install
```

---

## 📜 Доступные команды (NPM Scripts)

| Команда | Описание |
|---|---|
| `npm run dev` | Запуск локального сервера разработки Vite с Hot Module Replacement (HMR). Доступен по адресу `http://localhost:5173/`. |
| `npm run build` | **Основная команда валидации**: выполняет проверку типов TypeScript (`tsc -b`) и собирает оптимизированный production-бандл в папку `dist/`. |
| `npm run preview` | Локальный запуск production-сборки из папки `dist/` для проверки финальной сборки. |
| `npm run generate:svgs` | Запуск скрипта `scripts/generate_svgs.mjs` для генерации векторных SVG-аватарок персонажей в `public/avatars/`. |
| `npm run generate:og` | Генерация обложек для соцсетей (`og-cover.png`, `og-cover.jpg`, `og-image.*`) через `@resvg/resvg-js` и `sharp`. |
| `node scripts/build_renderer.mjs` | Синхронизация методов отрисовки персонажей из `src/game.ts` в `src/characterRenderer.ts` для Hero Lab. |

## 📐 Правила написания кода и архитектурные соглашения

### 1. Баланс и параметры игры
- Все балансные константы персонажей должны находиться **исключительно в [src/data/characters.ts](../src/data/characters.ts)**.
- Размеры арены, масштабы и общие тайминги должны находиться в [**`src/game/config.ts`**](../src/game/config.ts).
- Запрещено прописывать урон, HP, скорости или кулдауны в `index.html`, `hero-lab.html` или разметке кнопок.

### 2. Рендерер Canvas и Hero Lab
- Отрисовка бойцов на Canvas 2D пишется в методах класса `Fighter` файла [**`src/game.ts`**](../src/game.ts).
- **Не редактируйте `src/characterRenderer.ts` вручную**: после правки графики в `src/game.ts` обязательно запустите:
  ```bash
  node scripts/build_renderer.mjs
  ```

### 3. Разделение Canvas и DOM
- Canvas отвечает только за игровую сцену, физику, анимации и партиклы.
- Меню, экран выбора персонажей, экран победы и виртуальный тачпад оформляются через DOM-элементы с переключением CSS-классов (`.hidden`, `.active-p2`, `.fight-active`).
- Функции управления экранами выносите в [**`src/scenes/screenManager.ts`**](../src/scenes/screenManager.ts).

### 4. Поддержка мобильных устройств
- Все интерактивные элементы должны быть доступны как с клавиатуры, так и через тач-интерфейс (`#touchControls`).
- При добавлении новых кнопок действий учитывайте адаптацию для экранов с тачем.

## 🔍 Чеклист проверки изменений (Verification Checklist)

Перед завершением любой задачи обязательно выполните следующие проверки:

1. [ ] **Компиляция и сборка проекта**:
   ```bash
   npm run build
   ```
   Команда должна завершаться с кодом 0 (`built in ...ms`) без ошибок компилятора TypeScript (`tsc`).
2. [ ] **Синхронизация рендерера** (если менялись модели или анимации бойцов):
   ```bash
   node scripts/build_renderer.mjs
   ```
3. [ ] **Проверка дуэльного режима 1v1**:
   - Выбор бойцов P1 и P2.
   - Корректная работа легкого удара, тяжёлого удара, суперприёма и блока.
   - Корректное начисление побед в раундах и переход на экран `#winScreen`.
4. [ ] **Проверка режима Босса**:
   - Переключение в режим «☠ БОСС».
   - Тестирование режима «Босс: БОТ» и «Босс: ИГРОК».
   - Корректность кулдаунов и атак босса (`T`, `Y`, `G`, `H`, `V`, `B`, `N`).
5. [ ] **Проверка Hero Lab**:
   - Открытие `/hero-lab.html`.
   - Проверка переключения режимов «🎮 Модель» и «🎨 Арт».
   - Проверка кнопок анимаций (Стойка, Удар, Тяжёлый, Спец).
