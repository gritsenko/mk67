# Ростер персонажей и баланс «Друзья Файтинг»

В этом документе приведена спецификация всех 15 играбельных персонажей, Гига-Босса Тёмного Сергея, а также пошаговое руководство по добавлению нового бойца в игру.

---

## 📋 Схема конфигурации персонажа (`CharacterConfig`)

Все данные персонажей типизированы интерфейсом `CharacterConfig` в [**`src/data/characters.ts`**](../src/data/characters.ts):

```typescript
export interface CharacterConfig {
  id: string;                 // Уникальный идентификатор персонажа (латиница, нижний регистр)
  name: string;               // Отображаемое имя (русский язык)
  style: string;              // Стиль боя / класс персонажа
  icon: string;               // Короткая текстовая иконка для аватара-фоллбэка
  avatar: string;             // Относительный путь к файлу аватара ('avatars/<id>.svg' или '.jpg')
  color: string;              // Основной фирменный цвет (HEX) — используется в UI, частицах, искрах
  colorDark: string;          // Тёмный оттенок основного цвета — для теней и градиентов
  colorLight: string;         // Светлый оттенок основного цвета — для бликов и подсветки
  skin: string;               // Цвет кожи персонажа (HEX)
  
  // Боевые параметры (геймплейный баланс):
  hp: number;                 // Максимальный запас здоровья (стандарт: 80 - 140, босс: 420)
  speed: number;              // Скорость горизонтального бега (стандарт: 3.8 - 8.1)
  power: number;              // Базовая сила удара (стандарт: 9 - 18)
  defense: number;            // Коэффициент защиты: урон делится на это число (0.7 - 1.5)
  
  // Визуальные полосы характеристик в UI (0 - 100%):
  statATK: number;            // Рейтинг атаки в карточке
  statDEF: number;            // Рейтинг защиты в карточке
  statSPD: number;            // Рейтинг скорости в карточке
  
  // Габариты тела:
  bodyW: number;              // Ширина хёртбокса (влияет на попадания и расталкивание)
  bodyH: number;              // Высота хёртбокса
  
  // Суперприём:
  special: string;            // Название суперприёма
  specialDesc: string;        // Текстовое описание действия суперприёма
  specialCooldown?: number;   // Кулдаун в кадрах (по умолчанию 180 = 3 сек при 60 FPS)
  specialDamageMult?: number; // Множитель урона от базовой силы power (по умолчанию 2.2)
  
  // Опциональные механики спецприёма:
  projectile?: boolean;       // Запускает ли спецприём летящий снаряд
  projectileSpeed?: number;   // Скорость полёта снаряда
  dashVx?: number;            // Горизонтальный рывок бойца при активации
  leapVy?: number;            // Вертикальный импульс прыжка при суперприёме
  leapVx?: number;            // Горизонтальный импульс прыжка при суперприёме
  healPercent?: number;       // Доля восстанавливаемого HP (например, 0.2 = 20%)
  slowDuration?: number;      // Длительность замедления врага в кадрах
  slowFactor?: number;        // Множитель замедления врага (0.45 = снижение на 55%)
  bigExplosion?: boolean;     // Усиленный радиус взрыва и отдача экрана
  acidSplash?: boolean;       // Дополнительные брызги кислоты при детонации снаряда
  isBoss?: boolean;           // Флаг босса (активирует механику боссфайта)
}
```

## ☠️ Гига-Босс: Тёмный Сергей (`darksergey`)

- **Характеристики**:
  - `hp`: **420**
  - `speed`: 3.4
  - `power`: 15
  - `defense`: 1.25
  - `bodyW`: 190, `bodyH`: 330 (масштаб $1.35\times$)
  - `color`: `#76ff03` (кислотно-зелёный неон Бездны)
- **Способности**:
  1. `light` (Хлыст, клавиша `T`, урон 16)
  2. `heavy` (Пасть, клавиша `Y`, урон 28)
  3. `spikes` (Шипы, клавиша `G`, откат 4 сек)
  4. `wave` (Волна, клавиша `H`, урон 24, откат 5 сек)
  5. `rain` (Дождь, клавиша `V`, 5 снарядов по 14 урона, откат 6 сек)
  6. `clones` (Клоны, клавиша `B`, веер из 3 снарядов по 18 урона, откат 7 сек)
  7. `ulta` (УЛЬТА, клавиша `N`, глобальный взрыв при $HP < 40\%$, откат 12 сек)

## 🛠 Пошаговый гайд: добавление нового персонажа

Чтобы добавить нового бойца (например, с id `misha`), выполните следующие шаги:

### Шаг 1. Добавить запись в `src/data/characters.ts`
В массив `CHARACTERS` добавьте конфигурацию нового бойца:

```typescript
{
  id: 'misha',
  name: 'Миша',
  style: 'Берсерк',
  icon: 'Мш',
  avatar: 'avatars/misha.svg',
  color: '#ff5722',
  colorDark: '#bf360c',
  colorLight: '#ffab91',
  skin: '#e8b89d',
  hp: 110,
  speed: 5.8,
  power: 14,
  defense: 0.95,
  statATK: 75,
  statDEF: 60,
  statSPD: 70,
  bodyW: 64,
  bodyH: 126,
  special: 'Ярость медведя',
  specialDesc: 'Серия сокрушительных ударов с эффектом сотрясения земли.',
  specialCooldown: SPECIAL_COOLDOWN_FRAMES_DEFAULT,
  specialDamageMult: 2.2
}
```

### Шаг 2. Реализовать визуальный метод отрисовки в `src/game.ts`
В классе `Fighter` внутри `src/game.ts`:
1. Создайте метод `drawMisha(time, idle, walk)`:
   ```typescript
   drawMisha(time, idle, walk) {
     const C = this.data;
     // Код отрисовки ног, тела, головы, оружия при помощи Canvas 2D
   }
   ```
2. В методе `Fighter.draw()` добавьте ветку в `switch (C.id)`:
   ```typescript
   case 'misha': this.drawMisha(time, idle, walk); break;
   ```

### Шаг 3. Синхронизировать рендерер для Hero Lab
Запустите скрипт синхронизации:
```bash
node scripts/build_renderer.mjs
```
Скрипт автоматически обновит [**`src/characterRenderer.ts`**](../src/characterRenderer.ts), добавив модель Миши во все инспекторы Hero Lab.

### Шаг 4. Добавить арт/аватар
- Либо добавьте отрисовку карточки в `scripts/generate_svgs.mjs` и выполните `npm run generate:svgs`.
- Либо положите готовый SVG/JPG файл в `public/avatars/misha.svg`.

### Шаг 5. Сборка и проверка
Убедитесь, что TypeScript компилирует проект без ошибок:
```bash
npm run build
```
После этого новый боец автоматически появится в сетках выбора P1 и P2, а также на странице Hero Lab!
