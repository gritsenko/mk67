# Документация проекта «Друзья Файтинг» (mk67)

Добро пожаловать в документацию проекта **«Друзья Файтинг»** (репозиторий `gritsenko/mk67`).
Данная документация предназначена для разработчиков и автономных AI-агентов, работающих с кодовой базой проекта.

## ⚡ Краткая сводка о проекте

- **Жанр**: 2D файтинг в аркадном стиле Mortal Kombat.
- **Технологический стек**:
  - **Сборщик**: [Vite](https://vite.dev/) 6.x
  - **Язык**: TypeScript 5.x
  - **Графика**: HTML5 Canvas 2D (процедурный рендеринг персонажей, эффектов и арены)
  - **UI**: Семантический HTML5 + CSS3 (оверлеи поверх Canvas)
  - **Шрифты**: Google Fonts (*Russo One*, *Exo 2*) + локальные TTF в `scripts/`
  - **Скрипты сборки ассетов**: Node.js + `@resvg/resvg-js` + `sharp`
- **Ключевые фичи**:
  - 15 уникальных персонажей со своими характеристиками, стилями и суперприёмами.
  - Режимы 1v1: Игрок против Игрока, Игрок против Бота.
  - Рейд на ГИГА-БОССА Бездны (Тёмный Сергей, 420 HP, 7 уникальных способностей). Возможность управлять боссом вручную (Игрок) или отдать под управление ИИ.
  - Полноценная поддержка сенсорных экранов (виртуальный D-Pad + кнопки действий).
  - Интерактивный интерактив-справочник **Hero Lab** (`hero-lab.html`).
