# Инструкция для AI-агентов (agents.md)

Добро пожаловать в репозиторий **«Друзья Файтинг»** (`friends-fighting` / `mk67`).
Этот файл является оперативным руководством для автономных AI-агентов, парных ассистентов и разработчиков, вносящих изменения в данный проект.

---

## 🧭 Быстрый контекст проекта

- **Что это**: Браузерный 2D-файтинг в аркадном стиле Mortal Kombat. В игре представлены 15 уникальных бойцов со своими стилями и суперприёмами, режим 1v1 (Игрок против Игрока, Игрок против Бота), рейд против ГИГА-БОССА Бездны (Тёмный Сергей, 420 HP, 7 уникальных способностей), поддержка тач-устройств и отдельная интерактивная лаборатория персонажей [**Hero Lab**](./hero-lab.html).
- **Стек технологий**: [Vite](https://vite.dev/) 6.x, TypeScript 5.x, HTML5 Canvas 2D (процедурный рендеринг моделей и эффектов без растровых спрайтшитов), HTML5/CSS3 (DOM оверлеи интерфейса).
- **Сборка и валидация**:
  ```bash
  npm run build
  ```
  *(Запускает `tsc -b && vite build` — обязательная проверка перед сдачей любой задачи).*

## ⚠️ Критические правила для агентов (DOs and DON'Ts)

### 1. Единый источник правды для баланса
> [!IMPORTANT]
> Любые характеристики персонажей (HP, сила, скорость, защита, кулдауны, описания, цвета) **должны изменяться только в [`src/data/characters.ts`](./src/data/characters.ts)**.
> Общие игровые константы (разрешение холста, таймеры раундов, базовые масштабы) хранятся в [`src/game/config.ts`](./src/game/config.ts).
> **НИКОГДА** не зашивайте балансные значения, HP или кулдауны прямо в HTML-разметку!

### 2. Синхронизация кода отрисовки персонажей (`build_renderer.mjs`)
> [!WARNING]
> Графика и анимации персонажей пишутся в методах `Fighter` внутри [`src/game.ts`](./src/game.ts).
> Файл [`src/characterRenderer.ts`](./src/characterRenderer.ts) **генерируется автоматически**.
> Если вы изменили или добавили код отрисовки бойца в `src/game.ts`, **всегда запускайте**:
> ```bash
> node scripts/build_renderer.mjs
> ```
> Не редактируйте `src/characterRenderer.ts` вручную — эти изменения будут стёрты при следующей сборке.

### 3. Разделение Canvas и DOM
- Canvas отвечает **только** за рендеринг арены, бойцов, снарядов, партиклов и расчёт физики.
- Окна меню, карточки выбора персонажей, финальный экран победы и подсказки клавиш оформляются через DOM элементы.
- При создании новых экранов оформляйте их логику отдельным модулем в `src/scenes/`.

### 4. Границы игровых систем
- `src/game.ts` координирует матч и содержит `Fighter`; не переносите в него DOM-логику.
- Независимые от DOM системы оформляйте в `src/systems/` и передавайте им canvas/состояние через аргументы.
- Для частиц используйте API `spawnParticles`, `updateParticles`, `drawParticles`, `resetParticles` из `src/systems/particles.ts`; не создавайте второй глобальный массив частиц.
- Для фона используйте `createBackground()` и `drawBackground()` из `src/systems/background.ts`.

### 5. Поддержка мобильных устройств (Touch Controls)
- Проект полностью поддерживает сенсорные экраны через `#touchControls`.
- При добавлении новых действий или механик проверяйте, чтобы они были доступны как с клавиатуры, так и на тач-устройствах.

### 6. Обязательная проверка сборки
- После внесения любых изменений в код **всегда** выполняйте в терминале:
  ```bash
  npm run build
  ```
  Сборка должна завершаться успешно (`code 0`) без ошибок TypeScript.

## 🛠 Сценарии выполнения типовых задач (Recipes)

### Задача 1: Изменить баланс существующего бойца
1. Откройте [`src/data/characters.ts`](./src/data/characters.ts).
2. Найдите объект бойца по `id` в массиве `CHARACTERS`.
3. Измените нужные параметры: `hp`, `speed`, `power`, `defense`, `specialCooldown`, `specialDamageMult`.
4. Запустите `npm run build` для проверки. Изменения автоматически подхватятся игрой, карточками выбора и Hero Lab.

### Задача 2: Добавить нового бойца
1. Добавьте объект конфигурации нового бойца в `CHARACTERS` в [`src/data/characters.ts`](./src/data/characters.ts).
2. В классе `Fighter` в [`src/game.ts`](./src/game.ts) добавьте метод `draw<Name>(time, idle, walk)` и вызов в `switch (C.id)`.
3. Запустите `node scripts/build_renderer.mjs` для обновления `src/characterRenderer.ts`.
4. Поместите аватарку в `public/avatars/<id>.svg` (или сгенерируйте через `scripts/generate_svgs.mjs`).
5. Проверьте сборку: `npm run build`.

### Задача 3: Добавить новую механику боя / статус-эффект
1. Добавьте необходимые типы и параметры в `CharacterConfig` в [`src/data/characters.ts`](./src/data/characters.ts).
2. В классе `Fighter` ([`src/game.ts`](./src/game.ts)) добавьте поля состояния (таймер эффекта, флаг) в конструктор и метод `startRound()`.
3. Добавьте логику тика эффекта в `Fighter.update()`.
4. Добавьте логику наложения эффекта в `takeDamage()` или `checkHit()`.
5. Проверьте сборку: `npm run build`.

### Задача 4: Добавить новый оверлей / экран меню
1. Добавьте HTML-разметку с классом `.overlay` в [`index.html`](./index.html).
2. Добавьте ID экрана в тип `ScreenId` в [`src/scenes/screenManager.ts`](./src/scenes/screenManager.ts).
3. Добавьте функции открытия/закрытия экрана, используя `showScreen()` и `hideScreen()`.
4. Проверьте сборку: `npm run build`.
